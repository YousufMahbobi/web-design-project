# Selab Nadiry Travel & Tours

A responsive travel agency website for **Selab Nadiry Travel & Tours**, a travel agency based in Dubai.

## About the Project

This project is focused on building a modern and responsive travel agency website using **HTML5** and **CSS3**.

The main goal of this project is to practice and demonstrate fundamental front-end development skills, particularly:

* Semantic HTML5 structure
* Responsive web design
* CSS3 styling and layouts
* Flexbox and CSS Grid
* Responsive navigation
* Mobile-first design principles
* Clean and organized page structure

## Technologies Used

* **HTML5**
* **CSS3**

## Project Focus

For the current stage, the primary focus is on creating the website's **HTML structure, responsive layout, and visual design**.

Basic JavaScript will be implemented but the backend functionality may be added in future stages.

## Features

* Responsive layout for desktop, tablet, and mobile devices
* Travel agency homepage
* Navigation bar
* Hero section
* Travel and tour sections
* Services section
* About section
* Contact section
* Responsive images and content
* Clean and reusable CSS

## Project Status

🚧 **In Development**

This project is currently being developed as a front-end practice project. More features and functionality will be added over time.

## Purpose

This project was created to strengthen my practical knowledge of **HTML5 and CSS3** by building a real-world website rather than only following tutorials.
